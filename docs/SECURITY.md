# 凭据与数据

登录凭据由 Spring Security 在服务端验证。HttpOnly、SameSite Cookie 只携带 Session 标识，浏览器自动附带；JavaScript 不读写 Session 标识。
CSRF token 从后端取得，仅保存在内存，登录后刷新。只读和管理员权限由后端判断，隐藏按钮只是界面辅助。

前端不再包含登录密码，也不存业务数据到 IndexedDB/localStorage。旧浏览器数据库保留但不再读取。页面打开后的账号密码仍在浏览器内存、DOM 和剪贴板中，HttpOnly 并不能防止 XSS 读取业务数据。

生产环境使用 HTTPS 和 `SECURE_COOKIE=true`。本机 HTTP 调试使用 false。API 不应缓存。后端数据库密码与初始化哈希仅配置在后端/私密部署环境中，不放 `VITE_*`。

JSON 备份包含账号密码、邮箱密码、2FA、代理凭据和证据图片。导出到用户设备，恢复时上传后端。只读用户按约定也能完整导出，请仅给可信用户只读账户。
备份、`.env.local`、数据库转储均不得提交到公开仓库；`.gitignore` 不会删除过去提交中的内容，需要时另行处理历史并轮换凭据。

恢复会覆盖四个平台所有共享数据，但不更改两个登录账户与现有会话。不要把备份恢复当作单行导入。网络断开后不自动重试写请求，避免结果不明时重复写入。
